## 📋 Descripción

Sistema de consola que permite:
- Registrar productos (nombre, precio, cantidad).
- Validar que no se ingresen cantidades negativas ni precios inválidos.
- Mostrar alertas cuando un producto quede por debajo del stock mínimo.
- Listar productos y generar un resumen.
